# /tarot — タロット部門スラッシュコマンド

## 担当エージェント
**Mystic**（タロットコンテンツクリエイター）
参照: `agents/tarot/mystic.md`

---

## コマンドルーティング

### /tarot daily [日付/カード名]
**用途**: デイリータロット投稿の作成（1枚引き）
**起動**: Mystic（作成）→ Alex（QA）
**インプット**: 対象日付・カード名（指定がなければMysticがカードを選ぶ）
**アウトプット**: `templates/tarot-post.md` 形式
**例**: `/tarot daily 今日分`
**例**: `/tarot daily 明日分 愚者`

### /tarot weekly [対象週]
**用途**: 週間タロット投稿の作成（3枚引き・スレッド形式）
**起動**: Mystic（作成）→ Aria（ビジュアル指示）→ Alex（QA）
**インプット**: 対象週・任意のテーマ（指定がなければMysticが決める）
**アウトプット**: `templates/tarot-post.md` 形式（週間スレッド版）
**例**: `/tarot weekly 来週分`

### /tarot batch [本数] [期間]
**用途**: 複数デイリータロットの一括作成
**起動**: Sarah（テーマ方向性確認）→ Mystic（並列作成）→ Alex（一括QA）
**インプット**: 作成本数・対象期間
**アウトプット**: 複数の `templates/tarot-post.md`
**例**: `/tarot batch 7本 来週分`

### /tarot theme [テーマ] [展開法]
**用途**: 特定テーマのタロット投稿（恋愛・仕事・金運など）
**起動**: Mystic（作成）→ Alex（QA）
**インプット**: テーマ・枚数・展開法（1枚/3枚）
**アウトプット**: `templates/tarot-post.md` 形式
**例**: `/tarot theme 恋愛運 3枚引き`
**例**: `/tarot theme 転職・仕事 1枚引き`

### /tarot thread [テーマ]
**用途**: 教育的スレッド（カードの意味解説・タロット入門など）
**起動**: Mystic（作成）→ Alex（QA）
**インプット**: テーマ（カード名・スプレッド解説など）
**アウトプット**: スレッド形式（ツイート1〜8本の連投設計）
**例**: `/tarot thread タワーのカードの本当の意味`
**例**: `/tarot thread 初心者向けタロットの始め方`

### /tarot [自由記述]
**用途**: 上記に当てはまらないタロットコンテンツの依頼
**起動**: Mystic（判断して対応）
**インプット**: 依頼内容
**アウトプット**: Mysticによる対応
