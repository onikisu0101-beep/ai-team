# Instagram投稿テンプレート

## 使用方法
Emmaがフィード・Reels投稿を作成する際に使用する。
Aria（ビジュアル指示）・Alex（QAチェック）への提出もこのフォーマットで行う。

---

```
---
投稿ID: [YYYY-MM-DD]-insta-[連番 例:001]
作成者: Emma
作成日: [YYYY-MM-DD]
投稿予定日: [YYYY-MM-DD]
投稿形式: [カルーセル / Reels / ストーリーズ]
テーマ: [この投稿のテーマ 例: 謝罪の英語フレーズ5選]
難易度: [初級 / 中級 / 上級]
Sarahからの指示参照: [参照したコンテンツプランのID]
---

## 📸 コンテンツ内容

### ▼ カルーセルの場合

**スライド1（表紙）**
- タイトル: [キャッチコピー]
- サブテキスト: [補足一言]
- 視覚的ポイント: [目を引く要素]

**スライド2**
- メインテキスト（英語）: [英語フレーズ]
- 発音ヒント: [カタカナまたは音節]
- 日本語訳: [意味]
- 使い方説明: [どんな場面で・なぜ使う？]
- NG例（あれば）: [よくある間違い]

**スライド3**
（スライド2と同形式で繰り返し）

**スライド4**
（スライド2と同形式で繰り返し）

**スライドN-1（まとめ）**
- 今日覚えるフレーズ一覧:
  1. [英語フレーズ1] = [日本語訳]
  2. [英語フレーズ2] = [日本語訳]
  3. [英語フレーズ3] = [日本語訳]

**スライドN（CTA）**
- CTA文: [保存 / コメント / フォロー のうち1つ]
- 次回予告（あれば）: [次の投稿のヒント]

---

### ▼ Reelsの場合

**台本**
| タイムライン | セリフ / テキスト | 動作・画面指示 |
|-----------|--------------|------------|
| 0〜3秒（フック）| [セリフ/テキスト] | [動作・表情・テロップ位置] |
| 3〜10秒 | [コンテンツ本編] | [説明] |
| 10〜25秒 | [コンテンツ続き] | [説明] |
| 25〜30秒（CTA）| [保存/フォロー促し] | [テロップ表示] |

## 📝 キャプション

[1行目: フック（スクロールを止める一言）]

[本文: 投稿の補足・背景（200字以内）]

[CTA: 1つだけ]

[改行]
[ハッシュタグ（15〜25個、改行して末尾に）]
```
