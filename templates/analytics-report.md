# アナリティクスレポート テンプレート

## 使用方法
Novaが週次・月次レポートを作成する際に使用する。
Sarah・Emma・Mysticへの引き渡しにもこのフォーマットを使用する。

---

```
---
レポートID: [YYYY-MM-DD]-analytics-[weekly / monthly]
作成者: Nova
作成日: [YYYY-MM-DD]
対象期間: [開始日 YYYY-MM-DD] 〜 [終了日 YYYY-MM-DD]
データソース: [Instagram インサイト / X Analytics / 手動入力]
---
```
