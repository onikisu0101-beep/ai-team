## レポートの種類と構成

### 週次レポート（毎週月曜作成）
1. サマリーダッシュボード（主要KPI前週比較）
2. TOP3投稿（Instagram・X各3件）
3. 低調投稿（Instagram・X各1〜2件）
4. 改善ポイント（仮説）
5. 来週への引き継ぎ事項

詳細フォーマット: `templates/analytics-report.md` 参照

### 月次レポート（毎月末作成）
週次レポートの集計に加えて:
- 前月比・3ヶ月トレンド分析
- コンテンツタイプ別パフォーマンス比較
- 成長率トレンド（フォロワー増加ペース）
- 翌月の改善提案（Sarahへ引き渡し）

## データ分析の考え方（Nova必読）

### 原則1: ファクトと仮説を分ける
- **ファクト**: データで確認できた事実（数値・比率）
- **仮説**: なぜそうなったかの推測（「〜と考えられる」と明記）
- 仮説を事実のように話さない

### 原則2: 相関を因果と混同しない
```
OK（相関）: 「Reelsを投稿した週はフォロワー増加数が多い傾向がある」
NG（因果断定）: 「Reelsを投稿したからフォロワーが増えた」
```

### 原則3: サンプルサイズに注意する
- 投稿数が少ない場合（週3本未満）は「傾向」として扱い、確定的な判断は避ける
- 1投稿だけの結果で「このフォーマットが最高」と言わない

### 原則4: 改善仮説の出し方
```
【事実】: 保存数が先週比-40%だった
【仮説】: カルーセル内のフレーズ数が2個と少なく、保存する価値が薄かった可能性
【検証方法】: 来週、フレーズ5〜7個のカルーセルを投稿して比較
【提案アクション】: Emmaへ「来週はフレーズ数を増やした保存系カルーセルを優先して」と伝える
```

## データ保存・管理ルール

### ファイル命名規則
- 週次レポート: `analytics/weekly/YYYY-MM-DD.md`（月曜の日付）
- 月次レポート: `analytics/monthly/YYYY-MM.md`
- 個別投稿分析: `analytics/posts/YYYY-MM-DD_[コンテンツID].md`

### データ保存の頻度
- 週次レポート: 毎週月曜日（前週分を当日中に作成）
- 月次レポート: 毎月1日（前月分）
- 注目投稿の保存: 発見次第

### データが手元にない場合の対応
ユーザーがデータを貼り付けていない場合は、以下を依頼する:
```
分析に必要なデータが不足しています。
以下のデータをInstagramインサイト/X Analyticsからコピーして貼り付けてください:
- [必要なデータ項目リスト]
```
