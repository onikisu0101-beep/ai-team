# Instagram英語コンテンツ 運用マニュアル

## 概要
英語学習系Instagramアカウントの運用に関する詳細ガイドライン。
このマニュアルを読めば、一定水準以上のコンテンツを誰でも（どのエージェントでも）生成できる。

---

## コンテンツ種類と仕様

### 1. フィード投稿（カルーセル）
**目的**: 英語フレーズ・表現・文法の解説
**推奨スライド数**: 5〜10枚
**推奨投稿サイズ**: 1080×1080px（正方形）または 1080×1350px（縦長）

**標準構成テンプレート**:
```
スライド1（表紙）: キャッチーなタイトル + 英語フレーズのプレビュー1〜2個
スライド2〜N-2（本文）: フレーズ説明・例文・使い方・NG例・発音ヒント
スライドN-1（まとめ）: 今日覚えたいフレーズ一覧
スライドN（CTA）: 保存・フォロー促し + 次回予告
```

**表紙タイトルの作り方**:
- 数字を入れる: 「今すぐ使える英語フレーズ5選」「知らないと損！3つの表現」
- 疑問形: 「"Sorry"だけじゃない！謝罪の英語表現」「これ英語でなんて言う？」
- 共感形: 「英語でなんて言えばいいの？その悩みを解決します」
- 驚き形: 「日本人が間違えやすい英語No.1がこれ」

### 2. Reels
**目的**: 短い英会話・発音・フレーズ紹介
**推奨時間**: 15秒（豆知識）・30秒（フレーズ紹介）・60秒（会話シーン）

**台本構成テンプレート**:
```
0〜3秒（フック）: 「これ知ってた？」「こんな間違い、してない？」で注目を掴む
3〜25秒（コンテンツ）: メインの内容。テンポよく展開する
25〜30秒（CTA）: 「保存してね！」「フォローして毎日英語を学ぼう」
```

**Reels向けフレーズの選び方**:
- 視覚的に見せやすいもの（対比・NG/OK形式）
- 発音の違いがわかるもの
- 「へ〜！」という驚きがあるもの

### 3. ストーリーズ
**目的**: 日常的な英語豆知識・フォロワーとのインタラクション
**推奨形式**: テキスト重視、アンケート/クイズスタンプ活用
**投稿頻度**: 毎日1〜3投稿

---

## 英語コンテンツ品質基準

### 使用すべき英語レベル
- **メインターゲット**: CEFR A2〜B1（TOEIC 500〜700点相当）
- 日常会話で実際に使えるものを優先
- ビジネス英語・フォーマル表現は「上級」ラベルをつける

### 例文の書き方ルール
1. 文脈を明確にする（誰が・どんな場面で使うか）
2. 正しい英語と間違えやすい英語を対比で示す（NG/OK形式）
3. 音節や発音のコツを一言添える（例: ネイティブはここにアクセント）
4. 自然な省略形・短縮形を使う（I am → I'm など）

### 難易度表示（スライドに表記推奨）
- 初心者向け: ⭐ または [Basic]
- 中級者向け: ⭐⭐ または [Intermediate]
- 上級者向け: ⭐⭐⭐ または [Advanced]

---

## キャプションの書き方

### 構成
```
【1行目（フック）】: スクロールを止める一言（30字以内）

【本文】: 投稿の補足・背景・豆知識（200字以内推奨）

【CTA】: 保存/コメント/フォローを促す1つのアクション

【ハッシュタグ】: 改行して末尾にまとめて記載
```

### キャプション文体の原則
- 絵文字は適度に（1投稿に5〜10個）
- 改行をこまめに使い読みやすく
- 1文は短く（句読点で区切る）
- 「あなた」に語りかける2人称

---

## ハッシュタグ戦略

### 使用数の目安
- 総数: 15〜25個（多すぎるとスパム判定のリスク）

### 組み合わせパターン
- **ビッグタグ（100万投稿以上）**: 2〜3個（露出目的）
  例: #英語学習 #英語勉強
- **ミドルタグ（10万〜100万）**: 7〜10個（メイン流入）
  例: #英語フレーズ #英会話 #英語独学 #英語初心者
- **スモールタグ（1万〜10万）**: 5〜8個（ターゲット流入）
  例: #日常英会話フレーズ #英語キャプション #ネイティブ英語

### 固定タグ（毎投稿必ず含める）
※ユーザーがアカウント固有タグを設定してください
- #[アカウント固有タグ1]
- #[アカウント固有タグ2]

---

## 投稿スケジュール（推奨）
- **フィード投稿**: 週3〜5回
- **Reels**: 週2〜3回
- **ストーリーズ**: 毎日1〜3投稿
- **ベスト投稿時間**: Instagramインサイトで確認して設定（プレースホルダー）

---

## エンゲージメント向上テクニック
1. キャプションを質問で終わらせる（「あなたはどれが使いにくい？コメントで教えてね」）
2. クイズ形式の投稿（スライドの最後に「答えは次のスライドへ！」）
3. 「Part 2 が欲しい人はコメントで！」式の続編予告
4. フォロワーの英語フレーズリクエストに応える企画投稿
5. 「保存して後で使う」を促す実用的まとめスライド
