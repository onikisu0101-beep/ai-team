# 💾 ディスク容量管理ガイド（Windows）

> 目的: 「ディスク領域不足」通知（Windows Update失敗・動作重い・保存できない）を**再発させない**ための運用ルール。
> 対象: 澁谷優紀の制作用PC。素材ファイル（Reels動画・タロット画像）が重い業務のため、容量管理は制作の生命線。

---

## 🧭 基本方針: 「作業机」と「倉庫」を分ける

| 場所 | 役割 | 置くもの |
|------|------|---------|
| **PC本体ストレージ** | 作業机 | 今まさに編集中のファイルだけ |
| **外付けSSD / クラウド** | 倉庫 | 完成素材・過去データ・アーカイブ |

本体は常に **空き容量15〜20%以上** をキープする。これを切ると更新失敗・動作低下・保存エラーが発生する。

---

## 🚑 いま出ている通知を消す（今日やる）

上から順に実行。所要 約15分。

### 1. ディスク クリーンアップ
1. スタートボタン → 「ディスク クリーンアップ」と入力 → 開く
2. 対象ドライブ（通常 `C:`）を選択 → OK
3. 「システム ファイルのクリーンアップ」ボタンを押す（← これが重要。過去のWindows Update残骸を消せる）
4. チェックを入れる: 一時ファイル / 一時Windowsインストールファイル / 配信最適化ファイル / ゴミ箱
5. OK → 削除

### 2. ゴミ箱を空にする
- デスクトップのゴミ箱を右クリック → 「ゴミ箱を空にする」
- ※「削除」しただけでは容量は空かない。ここで確定させる

### 3. ダウンロードフォルダの整理
- エクスプローラー → ダウンロード
- 古いzip・画像・インストーラーを削除（一度使ったものは基本不要）

### 4. Windows Update を再実行
- 設定 → Windows Update → 「更新プログラムのチェック」→ インストール

---

## 🛡 再発防止の仕組み（1回設定すれば自動）

### A. ストレージセンサーをON ★最優先
一時ファイル・ゴミ箱を**自動で定期削除**してくれる機能。

1. 設定 → システム → 記憶域
2. 「ストレージ センサー」を **オン**
3. 「ストレージ センサーの構成」を開き:
   - クリーンアップの実行: **毎週**
   - ゴミ箱に移動してから削除: **14日**
   - ダウンロード フォルダー: 使い方次第（自動削除したくなければ「なし」）

### B. 素材ファイルを本体から逃がす
- 完成済みのReels動画・タロット画像は **外付けSSD** または **Googleドライブ** へ移動
- 本体には「編集中の案件」だけを残す
- 月末に「今月の完成素材」を倉庫へ移すのをルーティン化

### C. クラウド同期の設定を見直す
- OneDrive等を使っている場合、「ファイル オンデマンド」をON
  （＝普段はクラウドに置き、開くときだけDL。本体容量を節約）

---

## 📅 定期メンテナンス（習慣化）

| 頻度 | やること |
|------|---------|
| **毎週** | ストレージセンサーが自動実行（放置でOK） |
| **月1回** | 設定→システム→記憶域 で「何が容量を食っているか」チェック |
| **月1回** | 完成素材を倉庫（外付け/クラウド）へ移動 |
| **随時** | 空き容量が20%を切ったら素材を倉庫へ避難 |

---

## ⚠️ やってはいけないこと

- ❌ `Windows` フォルダや `Program Files` の中身を手動で削除する（システム破損の危険）
- ❌ 意味の分からないファイルを片っ端から消す → 迷ったら消さない
- ❌ 空き容量ゼロまで使い切る → 更新も保存もできなくなる

---

## 🔧 困ったときの早見表

| 症状 | 対処 |
|------|------|
| また通知が出た | 上記「今日やる」1〜3を実行 |
| クリーンアップしても空かない | 記憶域で犯人を特定 → 大きい素材を倉庫へ |
| Updateが失敗し続ける | 空き容量20%以上を確保してから再実行 |
| 何が容量食ってるか不明 | 設定→システム→記憶域 の内訳を見る |
