# タロット占いコンテンツ作成マニュアル

## 概要
X（旧Twitter）向けタロット占い投稿の作成に関する詳細ガイドライン。
このマニュアルを読めば、一定水準以上のコンテンツを誰でも（どのエージェントでも）生成できる。

---

## コンテンツ形式と仕様

### 1. デイリータロット（毎日投稿）
**文字数**: 100〜280字（Xの文字制限内）
**投稿時刻**: 毎朝6〜8時

**構成パターンA（シンプル型）**:
```
今日のカード: [カード名]（正位置/逆位置）

[エネルギーの説明 - 1文]

あなたへのメッセージ:
[今日のメッセージ - 2〜3文]

#タロット #今日のカード #デイリータロット
```

**構成パターンB（解説型）**:
```
今日引いたカードは「[カード名]」です。

[カードの絵柄・象徴の説明 - 1文]

このカードが現れる時、[状況の解釈 - 1文]。

今日のあなたへ: [メッセージ - 2文]

#タロット #デイリータロット #今日のカード
```

### 2. 週間タロット（週初め・月曜）
**形式**: スレッド（3ツイート連投）
**投稿時刻**: 月曜 8〜10時

```
ツイート1: [過去のカード] — 先週の流れ・手放すべきもの
ツイート2: [現在のカード] — 今週フォーカスすべきエネルギー
ツイート3: [未来のカード] — 週の終わりに向けてのメッセージ＋統合テーマ
```

### 3. テーマ別タロット
**テーマ例**: 恋愛、仕事・転職、金運、人間関係、健康、決断
**文字数**: 200〜280字

### 4. 教育スレッド（週1回）
**用途**: タロットの知識を深める・フォロワーのリテラシー向上
**例トピック**:
- 「[カード名]の本当の意味、正しく解釈できてる？」
- 「逆位置は"悪い"わけじゃない。正しい読み方を解説」
- 「3枚引きスプレッドの使い方：基本から応用まで」

## 文章スタイルガイド

### 積極的に使うべき表現
- 「〜かもしれません」「〜のサインかも」（断言を避ける）
- 「あなたの中にある〜」（内省を促す）
- 「このカードが伝えるのは〜」（カードを主語に）
- 「今週のエネルギーは〜」（時間軸を明確に）
- 「ヒントになれば嬉しいです」「参考にしてみてください」（押しつけない）

### 絶対に避ける表現
- 「絶対に〜になります」（断言）
- 「〜しなければ悪いことが起きます」（脅迫的）
- 「私に相談してください」（有料誘導に見える）
- 特定の個人名・有名人・事件への言及

## ハッシュタグ戦略

### 基本セット（毎投稿必ず含める）
```
#タロット #タロット占い #今日のカード
```

### 追加タグ（内容に応じて選択・2〜4個追加）
- デイリー系: #デイリータロット #毎日タロット
- 週間系: #今週の運勢 #週間タロット
- テーマ系: #恋愛運 #仕事運 #金運 #人間関係
- スピリチュアル系: #スピリチュアル #宇宙のメッセージ #直感
- 大アルカナ系: #[カード名のカード]（例: #愚者のカード）

## 投稿スケジュール
- **デイリータロット**: 毎朝 6〜8時（毎日）
- **週間タロット**: 月曜 8〜10時（週1）
- **テーマ別タロット**: 週2〜3回（任意の時間）
- **教育スレッド**: 週1回（水〜金の19〜21時推奨）
