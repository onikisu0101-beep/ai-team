# コピーライティングルール ガイドライン

## 概要
Instagram・X全投稿に共通するコピーライティングの基本ルール。
「読まれるテキスト」を書くための実践的なガイドライン。全エージェント必読。

---

## 基本原則

### 原則1: 最初の1行がすべて
InstagramもXも、最初の1〜2行でスクロールを止めなければならない。
フックなしのコンテンツは、いくら内容が良くても読まれない。

**フックパターン一覧**:
| タイプ | 例 |
|-------|---|
| 数字系 | 「英語フレーズ5選」「3秒で使える表現」「9割の人が知らない〇〇」|
| 疑問系 | 「"Sorry"しか言えていない？」「これ、英語でなんて言う？」|
| 共感系 | 「英語で謝りたいのに言葉が出てこない」「なんとなく英語が苦手なあなたへ」|
| 驚き系 | 「日本人が間違えやすい英語No.1がこれ」「実はこの表現、失礼なんです」|
| 結論先出し系 | 「結論: ネイティブは"very"をほとんど使わない」|

### 原則2: 箇条書き・改行を積極活用する
読みやすさは「見た目」から来る。ブロック文章は読まれない。

**良い例**:
```
今日覚えたい英語フレーズ ✏️

① I really appreciate it.
→ 本当にありがとうございます（感謝を強調）

② I couldn't have done it without you.
→ あなたなしではできなかった

保存してね！📌
```

**悪い例**:
```
今日覚えたい英語フレーズはI really appreciate it.で本当にありがとうございますという意味です。感謝を強調したい時に使います。次にI couldn't have done it without you.であなたなしではできなかったという意味です。
```

### 原則3: CTAは1投稿に1つだけ
複数のCTAを入れると読者が迷って行動しない。最重要なものを1つだけ選ぶ。

**CTAの優先順位**:
1. **保存**: ストック系コンテンツ（フレーズ集・まとめ系）
2. **コメント**: エンゲージメント重視の投稿
3. **フォロー**: 新規認知拡大フェーズ
4. **シェア**: 拡散を狙う投稿

**CTA文例集**:
- 「保存して後で使ってね📌」
- 「役に立った？コメントで教えて！」
- 「フォローして毎日英語をインプットしよう」
- 「英語が苦手な友達にシェアしてあげて」

## プラットフォーム別ルール

### Instagram
| 要素 | ルール |
|-----|-------|
| 絵文字 | 1投稿5〜10個。見出しや区切り・強調に使う |
| 改行 | こまめに。1〜2文ごとに改行してOK |
| ハッシュタグ | キャプション末尾にまとめて記載（本文に混ぜない） |
| 文字数 | キャプション2,200字まで。実際は300字以内が読まれやすい |
| 1文の長さ | 40字以内を目安に。長い文は分割する |

### X（Twitter）
| 要素 | ルール |
|-----|-------|
| 文字数 | 140字以内が理想（日本語は1文字1カウント）|
| 絵文字 | Instagram より控えめ。2〜3個が目安 |
| ハッシュタグ | 本文内か末尾に1〜3個。多すぎるとスパム判定 |
| スレッド | 2ツイート目以降は「続き→」の形で誘導 |
| 改行 | 1〜2行の空白を入れると読みやすい |

## 英語コンテンツの見せ方（Emmaが参照）

### フレーズの標準フォーマット
```
英語: I really appreciate it.
読み方: アイ・リアリー・アプリーシエイット
意味: 本当にありがとうございます（感謝を強調）
使う場面: 助けてもらった時、深い感謝を伝えたい時
NG例: Thank you. だと少し素っ気ない場面でも使える
ポイント: "appreciate" がキーワード。覚えておいて！
```

### NG/OK対比フォーマット
```
❌ NG: "I want go to the shop."
✅ OK: "I want to go to the shop."
👉 "want to" の "to" を忘れずに！
```

## タロット投稿の書き方（Mysticが参照）

### 原則
1. **カードを主語にする**: 「このカードが伝えるのは...」
2. **読者の内省を促す**: 「あなたの中に...」
3. **行動を促す**: 読んだ後に「何かしてみよう」と思えるメッセージ
4. **詩的すぎない**: わかりやすさを最優先

### NG表現 → OK表現の変換例
| NG | OK |
|----|---|
| 「絶対にうまくいきます」 | 「うまくいく流れが来ているかもしれません」|
| 「危険な時期です」 | 「少し慎重に行動すると良い時期のようです」|
| 「相談してください」 | 「もし迷ったら、立ち止まって内省してみて」|

## よくある間違い修正集

### 間違い1: 受け身すぎる締め
NG: 「このフレーズが参考になれば幸いです」
OK: 「このフレーズ、明日から使ってみて！」

### 間違い2: 内容が薄い
NG: 「Sorry は謝罪の表現です」
OK: 「"Sorry"には3用途ある。①軽い謝罪②同情③聞き返し。場面で使い分けよう」

### 間違い3: CTAがない
NG: 「今日はここまで。ありがとうございました。」
OK: 「この投稿、役に立った？保存して後で使ってね📌」

### 間違い4: 一文が長すぎる
NG: 「英語で謝罪するときには状況に応じてさまざまな表現を使い分けることが大切で、軽い謝罪には"Sorry"で十分ですが、より丁寧に謝りたい場合には"I apologize"を使うとより誠意が伝わります。」
OK: 「軽い謝罪 → "Sorry" / より丁寧に → "I apologize" / 深い謝罪 → "I sincerely apologize"」
