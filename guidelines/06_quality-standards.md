# 品質基準 ガイドライン

## 概要
全コンテンツが満たすべき品質基準を定義する。
Alexが品質管理を行う際のチェックリストと判定基準。

---

## 品質レベルの定義

| レベル | 説明 | 対応アクション |
|------|-----|------------|
| **S** | すべてのチェック項目をクリア。追加修正なしで公開可能 | ユーザーへ即時提出 |
| **A** | 1〜2箇所の軽微な修正が必要（誤字・ハッシュタグ等）| 修正後に再チェック不要で提出 |
| **B** | 内容の修正が必要。ブランドや品質への影響がある | 担当エージェントに差し戻し＋再チェック |
| **C** | 内容・方向性が基準を大きく外れている | 担当エージェントに差し戻し＋Sarahに状況報告 |

---

## 共通チェックリスト（全コンテンツ必須）

### 基本品質
- [ ] 誤字・脱字がない
- [ ] 文章が自然で読みやすい
- [ ] 改行・段落が適切
- [ ] 絵文字の使い方が適切（使いすぎていない・少なすぎない）

### ブランドアライメント
- [ ] `guidelines/01_brand-identity.md` のブランドボイスと一致している
- [ ] NGコンテンツリストに抵触していない
- [ ] アカウントの世界観と合っている

### CTA・ハッシュタグ
- [ ] CTAが明確（必要なコンテンツのみ・1つだけ）
- [ ] ハッシュタグが適切な数と内容（プラットフォーム別ルール準拠）
- [ ] スパムにならない使い方

---

## Instagram英語コンテンツ 追加チェックリスト

### 英語の正確性（最重要）
- [ ] 英文に文法ミスがない
- [ ] スペルミスがない
- [ ] 意味・ニュアンスが正確（日本語訳と一致している）
- [ ] ネイティブが実際に使う自然な表現か（古い/地域限定の表現でない）
- [ ] 発音ヒントがある場合、正確か

### 教育コンテンツとして
- [ ] ターゲットの英語レベルに合っている（CEFR A2〜B1）
- [ ] 説明がわかりやすい（難しい英語で英語を説明していない）
- [ ] 例文が実用的かつ日常で使えるもの
- [ ] 学習者が「ためになった」「保存したい」と思える内容

### フォーマット
- [ ] スライド構成がガイドラインに準じている（`guidelines/02_instagram-english-guide.md`）
- [ ] ハッシュタグ数が15〜25個の範囲内

---

## Xタロット投稿 追加チェックリスト

### タロット解釈の適切性
- [ ] カードの意味・解釈が妥当（`guidelines/03_tarot-content-guide.md` の意味表と大きく乖離していない）
- [ ] 正位置・逆位置の使い方が適切

### 倫理・リスク管理
- [ ] 断言的すぎる表現がない（「絶対に〜」「必ず〜」）
- [ ] 不安を煽る表現がない
- [ ] 特定個人への言及がない
- [ ] 有料占いへの過度な誘導がない
- [ ] 読者が精神的に依存してしまうような内容でない

### フォーマット
- [ ] 文字数が280字以内（Xの上限）
- [ ] ハッシュタグが1〜5個の適切な範囲

## 品質判定フロー

```
コンテンツ受け取り
    ↓
共通チェック実施
    ↓
プラットフォーム別追加チェック実施
    ↓
品質レベル判定（S / A / B / C）
    ↓
S → ユーザーへ提出
A → 軽微修正後にユーザーへ提出（再チェック不要）
B → 担当エージェントに差し戻し（修正箇所・理由・修正案を明記）
      → 修正後にAlexが再チェック
C → 担当エージェント + Sarahへ報告 + ユーザーに状況共有
```

## フィードバックの書き方ルール（Alex必読）

### 必ず「NG → OK → 理由」の三点セットで書く
```
【修正箇所】: スライド2の英文
【現状（NG）】: "I want go to the shop."
【修正案（OK）】: "I want to go to the shop."
【理由】: to不定詞の "to" が欠けています。正しい文法は "want to + 動詞の原形" です。
【優先度】: 必須
```

### トーンのルール
- 感情的な表現は使わない
- 「ここがダメ」ではなく「この点で品質基準を満たしていません」
- 必ず改善案を添える（問題だけ指摘して終わらない）
- ポジティブな点も1〜2つ言及する

### 優先度の設定
- **必須**: 公開前に必ず直すべき（誤情報・文法ミス・NGコンテンツ等）
- **推奨**: 直した方が品質が上がる（表現の改善・CTA追加等）
- **任意**: 改善案の提案（やってもやらなくてもよい）
